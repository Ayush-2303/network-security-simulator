5G Network Slicing with Wireshark Traffic Analysis

Use measured traffic rates and packet patterns to automatically assign 5G slices and allocate bandwidth.

1. Import Wireshark traffic

In Wireshark: File → Export Packet Dissections → As CSV. Upload that CSV here first.

3. Add a device

Choose an IP above and enter any label, such as 1, 2, or 3. The name does not affect slicing.

4. Automatic traffic-based slice analysis

Short-capture rules: eMBB for at least 0.05 Mbps or 50,000 bytes; URLLC candidate for at least 10 small packets (average size at most 600 bytes); otherwise mMTC. Your typed device name does not affect this decision.

5. Predicted bandwidth allocation from Wireshark data

Predicted demand uses the captured packet count and observed Mbps to adjust a slice baseline: URLLC 10 Mbps, eMBB 25 Mbps, mMTC 2 Mbps. The 100 Mbps pool is then allocated URLLC → eMBB → mMTC.
